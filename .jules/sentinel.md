## 2024-05-12 - IDOR Vulnerability in PDF Generation Endpoints
**Vulnerability:** Insecure Direct Object Reference (IDOR) on PDF generation endpoint for payrolls (`KaryawanSlipGajiController@generatePDF`). The endpoint accepted a `Payroll` object directly (via implicit route binding) and allowed downloading its PDF without verifying that the authenticated employee owned the payroll record, or that the payroll was in a finalized status.
**Learning:** Even when models use obfuscated identifiers like `HashIdRoute`, it is not a sufficient replacement for proper authorization checks. Endpoints that generate or return data based on route bindings can still expose sensitive information if explicit ownership and status checks are omitted.
**Prevention:** Always implement explicit ownership checks (e.g., `$payroll->employee_id !== $employee->id`) and state checks (e.g., verifying status is `approved_finance` or `paid`) on all endpoints that return direct object references, regardless of route obfuscation mechanisms.
