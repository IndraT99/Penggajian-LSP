## 2024-05-16 - Missing Authorization in PDF Generation Endpoint
**Vulnerability:** The endpoint to generate PDF for salary slip (`generatePDF` method in `KaryawanSlipGajiController`) lacked proper authorization checks. Although the `show` method had correct checks, the PDF download endpoint was relying on route model binding without verifying if the user generating the PDF was indeed the owner of the `Payroll` object and that the payroll was in a finalized state.
**Learning:** File/PDF generation endpoints are commonly overlooked for authorization checks, as developers focus on the view/generation logic instead of access control, especially when using route model binding with ID obfuscation. Route obfuscation is NOT authorization.
**Prevention:** Always explicitly check authorization (ownership and valid state) against the authenticated user on all endpoints returning direct object references, including file and PDF downloads, regardless of whether route IDs are obfuscated.
