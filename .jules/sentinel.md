
## 2024-05-24 - IDOR Vulnerability in PDF Generation Endpoint
**Vulnerability:** Insecure Direct Object Reference (IDOR) on PDF download routes. Even though the application uses `HashIdRoute` for obfuscated route keys, the `generatePDF` method in `KaryawanSlipGajiController` returned PDF files for any valid payroll ID without verifying that the authenticated user owned the payroll record or that the payroll state allowed it to be viewed. This allowed users to potentially guess obfuscated IDs (or find them elsewhere) and access other employees' pay slips.
**Learning:** Developers often focus heavily on the mechanics of third-party packages (like `barryvdh/laravel-dompdf`) and view generation, neglecting standard access controls and state checks on download endpoints. Obfuscated IDs (`HashService`) are a supplementary measure and do not replace the need for strict authorization (`$model->user_id === Auth::id()`).
**Prevention:** Always implement explicit ownership authorization and appropriate state checking (e.g., ensuring draft/pending documents aren't leaked) on endpoints that return direct object references, files, or generated media, regardless of whether route keys are obfuscated.
