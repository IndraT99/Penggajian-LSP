## 2024-05-24 - IDOR in PDF Generation Endpoint
**Vulnerability:** Insecure Direct Object Reference (IDOR) on the PDF generation route (`generatePDF` method in `KaryawanSlipGajiController`). Although route model binding and hashing obfuscate the direct IDs, the lack of explicit authorization checks in the endpoint allowed any authenticated user to potentially download any payroll slip PDF.
**Learning:** Endpoints that return files or PDFs often get overlooked when applying authorization checks, especially when developers assume ID obfuscation or route model binding implicitly provides security. The view endpoints (like `show`) had proper checks but the download/generation endpoints did not.
**Prevention:** Always implement explicit ownership (`employee_id` == authenticated `employee_id`) and state checks (`status` is final) directly inside controller actions that provide access to sensitive resources, regardless of whether the ID is obfuscated or if the action just returns a file.
