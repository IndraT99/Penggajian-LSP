## 2025-02-20 - Fix IDOR in Payroll PDF Generation
**Vulnerability:** Insecure Direct Object Reference (IDOR) on the PDF generation endpoint `generatePDF` in `KaryawanSlipGajiController`. The endpoint was lacking ownership verification and status checking, allowing any authenticated user to download the PDF slip of any payroll by guessing its ID.
**Learning:** Endpoints that generate or return files (like PDFs) are frequently overlooked when implementing authorization, as developers might focus purely on the view generation aspect rather than securing access control on the resource itself. Even with obfuscated IDs via `HashService`, direct object references must always explicitly check for authorization and appropriate final object states (e.g., `approved_finance` or `paid`).
**Prevention:** Always implement explicit ownership and state checks on any endpoint returning a direct object reference or file. Verify not just `if the user owns it` but also `is this object in a state that should be accessible by the user`.
