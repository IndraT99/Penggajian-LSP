## 2024-05-15 - Prevent IDOR in File Download Endpoint
**Vulnerability:** The `/karyawan/slip-gaji/{payroll}/pdf` endpoint (handled by `KaryawanSlipGajiController@generatePDF`) did not check if the requested payroll slip belonged to the authenticated user. This allowed any authenticated employee to download the PDF slip of any other employee by simply changing the payroll ID, which is a classic Insecure Direct Object Reference (IDOR) vulnerability.
**Learning:** Endpoints returning files/PDFs are particularly susceptible to IDOR because developers often focus on the view generation logic and overlook the access control checks. Route obfuscation (like hashing IDs) is insufficient protection against unauthorized data access.
**Prevention:** Always implement explicit ownership checks and data state validations (e.g., ensuring a document is fully approved/finalized) on endpoints that return files or direct object references, even if the routes use obfuscated identifiers.
