## 2024-05-18 - Fix Insecure Direct Object Reference (IDOR) in File Generation Endpoint
**Vulnerability:** The `/karyawan/slip-gaji/{payroll}/pdf` endpoint (handled by `generatePDF` in `KaryawanSlipGajiController`) generated PDF files using Route Model Binding but failed to verify if the requesting authenticated user owned the `Payroll` object or if the `Payroll` object was finalized (`approved_finance` or `paid`). This exposed sensitive payroll data of all employees in all states to any authenticated user.
**Learning:** Endpoints that return files (like PDFs or images) are often overlooked when applying authorization checks, as developers focus heavily on the data-rendering logic (e.g. view HTML generation) but forget that the same ownership and status restrictions apply to the file stream. Route obfuscation (`HashIdRoute`) does not prevent unauthorized access if an ID is leaked or guessed.
**Prevention:** Always implement explicit authorization checks (`$payroll->employee_id === $employee->id`) and state validation (`in_array($payroll->status, ['approved_finance', 'paid'])`) on every endpoint that retrieves or interacts with models, especially those returning file streams or raw data, independently of obfuscation layers.
