## 2024-05-24 - Missing Authorization on PDF Download Endpoint (IDOR)
**Vulnerability:** The `KaryawanSlipGajiController@generatePDF` endpoint accepted a `Payroll` object via route model binding but failed to verify if the authenticated employee owned the requested payroll record. This allowed an attacker to guess or enumerate IDs and download slip gaji PDFs of other employees. Additionally, the endpoint did not check the payroll `status`, potentially exposing draft or unapproved payrolls.
**Learning:** Endpoints that generate or return files (like PDFs) are frequently overlooked for authorization checks, as developers may mistakenly assume that the view/route obfuscation or the simple act of generating a file does not require the same rigorous checks as viewing data in a web page. Route obfuscation (via `HashService`) is not a replacement for proper authorization.
**Prevention:** Always implement explicit ownership checks (`$model->owner_id === $currentUser->id`) and state checks (`$model->status === 'finalized'`) on endpoints returning direct object references, especially those generating files, even if the routes use hashed or obfuscated IDs.
