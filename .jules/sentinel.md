## 2024-05-24 - Missing Authorization on PDF Generation Endpoint
**Vulnerability:** Insecure Direct Object Reference (IDOR) on PDF download endpoints. Endpoints returning files/PDFs (like `KaryawanSlipGajiController@generatePDF`) failed to check authorization/ownership, allowing any authenticated user to download any other user's file by guessing/iterating over the object ID (even with route model binding and obfuscated IDs).
**Learning:** Route obfuscation using `HashService` or `HashIdRoute` is not a substitute for proper authorization. Developers often focus on view generation (like using `Barryvdh\DomPDF\Facade\Pdf`) and overlook access control on these endpoints compared to standard `show` methods.
**Prevention:** Always explicitly check authorization and ownership against the authenticated user for all endpoints that return direct object references, especially those generating or returning files. Additionally, verify state (like `status`) to ensure only finalized data is accessible.
