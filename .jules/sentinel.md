## 2024-05-24 - IDOR in PDF Download & Unprotected Utility Routes
**Vulnerability:** Found an Insecure Direct Object Reference (IDOR) vulnerability in `KaryawanSlipGajiController@generatePDF` that allowed any authenticated user to download any other user's payslip PDF if they knew the payroll ID. Additionally, setup and debug routes (`/setup-database`, `/fix-ssl`) were exposed without authentication or authorization, potentially leading to unauthorized data manipulation or denial of service.
**Learning:** Route model binding does not automatically enforce ownership. Endpoints that trigger actions like PDF generation must explicitly verify that the authenticated user owns the requested resource and that the resource is in a state appropriate for access (e.g., status is `paid`). Utility routes must never be placed in the public `web.php` without strict access controls.
**Prevention:** Always implement explicit authorization checks (e.g., using `$this->getAuthenticatedEmployee()`) against the authenticated user's ID within the controller action, especially for sensitive document downloads. Group administrative utility routes under appropriate middleware (`auth`, `role:admin`) to enforce strict access controls.
