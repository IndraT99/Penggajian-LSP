## 2025-03-03 - [Fix IDOR in PDF Generation]
**Vulnerability:** The KaryawanSlipGajiController's generatePDF endpoint suffered from an Insecure Direct Object Reference (IDOR), allowing authenticated users to fetch other employees' payroll slips if they knew the payroll ID. The endpoint also failed to check the payroll status, allowing download of draft/unapproved payrolls.
**Learning:** Endpoints that bypass standard view generation (e.g., returning raw files, PDFs, or external streams) are frequently missed when applying standard route authorization or model binding checks. Furthermore, relying on route ID obfuscation (like HashIdRoute) is not a robust substitute for true authorization logic.
**Prevention:** Always implement explicit ownership checks (`$model->user_id === $authenticatedUser->id`) and state validation (`in_array($model->status, [...])`) inside controller methods that handle direct object references or sensitive file returns. Use established helper methods (like `$this->getAuthenticatedEmployee()`) to enforce authorization before serving content.
