## 2024-03-24 - Missing Authorization on PDF Generation Endpoint
**Vulnerability:** Insecure Direct Object Reference (IDOR) on KaryawanSlipGajiController@generatePDF, allowing authenticated users to bypass route ID obfuscation and generate PDF payslips for other employees by guessing the underlying incremental ID.
**Learning:** Endpoints that generate or return files (like PDFs) are often overlooked for authorization checks, with developers assuming that if the view route is protected, the file generation route implicitly is too. Additionally, using route model binding with an obfuscated ID (via HashService) provides false security if explicit ownership and status checks are not implemented at the controller level.
**Prevention:** Always implement explicit authorization checks (e.g., verifying `employee_id` belongs to the authenticated user and `status` is finalized) on endpoints returning direct object references or generating files, regardless of whether the IDs are obfuscated in the route.
