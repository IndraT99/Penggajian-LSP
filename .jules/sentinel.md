## 2024-07-25 - IDOR in PDF Generation Endpoint
**Vulnerability:** The `generatePDF` endpoint for payroll slips lacked authorization checks. Although the route used route model binding, it did not verify if the requested `Payroll` record belonged to the currently authenticated user, or if the payroll was in a finalized state (`approved_finance` or `paid`).
**Learning:** File generation endpoints (like PDF exports or downloads) are frequently overlooked when implementing access control. Developers often focus on the main view/show routes and forget to apply the same strict ownership and status checks to related utility endpoints. Route obfuscation (like hashed IDs) is insufficient protection against this.
**Prevention:** Always implement explicit ownership checks (`$model->user_id === Auth::id()`) and necessary state/status checks on *all* endpoints that return direct object references, regardless of whether they return a view, JSON, or a file download. Ensure parity of access controls across all related endpoints for a given resource.
