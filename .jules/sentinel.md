## 2025-04-22 - Missing Authorization and State Check in PDF Generation
**Vulnerability:** The `generatePDF` method in `KaryawanSlipGajiController` accepted a `Payroll` object directly (via route model binding) but lacked an explicit ownership check (`$payroll->employee_id === $employee->id`) and state check (`in_array($payroll->status, ['approved_finance', 'paid'])`). This allowed an Insecure Direct Object Reference (IDOR) where any authenticated user with the correct route hash could download another employee's unapproved or approved payroll slip as a PDF.
**Learning:** Even if a controller's `show` method has correct authorization checks, secondary endpoints associated with the same resource (like PDF generation or exports) often overlook these checks. Route obfuscation (`HashService`) provides false security and doesn't replace true authorization.
**Prevention:** Always verify ownership and state explicitly in every endpoint that returns a direct object reference, particularly for exports/downloads. Duplicate or abstract authorization logic (e.g., using Laravel Policies or FormRequests) rather than relying on route obscurity.
