## 2025-02-14 - Fix IDOR in Payroll PDF Generation Endpoint
**Vulnerability:** The `/karyawan/slip-gaji/{payroll}/pdf` endpoint (in `KaryawanSlipGajiController@generatePDF`) generated PDFs by directly passing a `Payroll` model via route-model binding without validating if the authenticated user owned that payroll or if the payroll status was final (e.g. `approved_finance` or `paid`). This resulted in an Insecure Direct Object Reference (IDOR) vulnerability.
**Learning:** Even if an object is accessed directly via route model binding and/or route ID obfuscation (like `HashIdRoute` with `HashService`), explicit authorization (ownership) and state (status) checks are absolutely mandatory in controllers to prevent unauthorized access.
**Prevention:** Always implement explicit ownership checks (e.g., matching the resource's `employee_id` with the authenticated user's `employee_id`) and status checks for stateful entities in every controller action, particularly on endpoints returning files/PDFs.
