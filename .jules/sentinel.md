## 2024-05-18 - Missing Authorization on PDF Download Endpoint
**Vulnerability:** Insecure Direct Object Reference (IDOR) on the PDF generation endpoint `slip-gaji/{payroll}/pdf`. The endpoint allowed users to download other users' salary slips by guessing the obfuscated ID, as it lacked authorization checks to verify ownership and finalized status.
**Learning:** Endpoints that generate or return files (like PDFs) are frequently overlooked for authorization checks, as developers might focus solely on the view/generation logic and assume obfuscated IDs (via `HashService` or `HashIdRoute`) provide security. Route obfuscation is not a substitute for proper authorization.
**Prevention:** Always implement explicit ownership (`$payroll->employee_id === $employee->id`) and state checks (`in_array($payroll->status, ['approved_finance', 'paid'])`) on all endpoints returning direct object references, especially those dealing with sensitive files like salary slips, regardless of route key obfuscation.
