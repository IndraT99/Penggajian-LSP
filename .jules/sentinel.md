## 2026-06-16 - [Missing Authorization Checks in File Generation Endpoints]
**Vulnerability:** Insecure Direct Object Reference (IDOR) on PDF file generation endpoint (`app/Http/Controllers/Karyawan/KaryawanSlipGajiController.php`). Although there was authorization check for viewing the slip on `show` method, the `generatePDF` method was missing these checks, allowing any authenticated user to potentially download PDF slip salaries of other users.
**Learning:** Endpoints that generate and return files (like PDFs) are often overlooked when developers focus on the view generation aspect. Route model binding obfuscation (like `HashIdRoute`) doesn't replace explicit authorization checks on sensitive stateful models, as obfuscated IDs might still be leaked.
**Prevention:** Always implement explicit ownership (`$payroll->employee_id === $employee->id`) and state checks (`in_array($payroll->status, [...])`) on all endpoints returning direct object references or sensitive files, regardless of route model binding or obfuscation mechanisms.
