## 2024-05-18 - Insecure Direct Object Reference (IDOR) in KaryawanSlipGajiController@generatePDF
**Vulnerability:** The `generatePDF` method in `app/Http/Controllers/Karyawan/KaryawanSlipGajiController.php` lacks ownership and authorization checks. It directly accepts a `Payroll` model and generates a PDF for it. Since route parameter models are resolved by Laravel's route model binding (often utilizing hashed IDs via HashIdRoute in this project, but obfuscation isn't security), any authenticated user could guess or brute-force a payroll ID to download another employee's salary slip, exposing sensitive financial data.
**Learning:** Even with route ID obfuscation (like HashService), direct object references must always be explicitly validated against the currently authenticated user's ownership. Additionally, state checks (like `status`) must be enforced on all endpoints returning data, not just on views, as developers often focus on the visual presentation rather than the raw data/file generation endpoints.
**Prevention:** Always use `$employee = $this->getAuthenticatedEmployee();` (or equivalent pattern) and verify `$payroll->employee_id === $employee->id` and proper status before proceeding with the operation in any controller method that handles sensitive entities.
