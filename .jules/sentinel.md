## 2024-08-09 - Fix IDOR in payroll PDF generation
**Vulnerability:** Insecure Direct Object Reference (IDOR) on PDF generation endpoint for payroll slips. The controller method (`generatePDF`) used route model binding (`Payroll $payroll`) without verifying if the authenticated user owned the payroll record, or if the payroll record was finalized. This allowed any authenticated user to guess payroll IDs and view any employee's sensitive salary details.
**Learning:** Endpoints that generate or return files/PDFs are prone to IDOR because developers often focus on the file generation logic (e.g., using `Pdf::loadView`) and forget to apply the same authorization checks used in standard view endpoints (like the `show` method).
**Prevention:** Always verify ownership and state authorization explicitly for every endpoint that accepts an object ID, especially those returning files or sensitive data. Route obfuscation (like `HashIdRoute`) is insufficient protection against unauthorized access.
