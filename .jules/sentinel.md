## 2024-05-15 - Prevent IDOR on PDF Generation Endpoints
**Vulnerability:** Insecure Direct Object Reference (IDOR) on the `generatePDF` endpoint in `KaryawanSlipGajiController`. The endpoint directly accepted a `Payroll` object (via route model binding) and generated a PDF without verifying that the payroll record belonged to the authenticated user and without checking if its status was finalized.
**Learning:** Endpoints that generate or return files (like PDFs) are often overlooked for authorization checks, as developers might mistakenly rely on obfuscated IDs or assume that the data retrieval process (e.g., viewing the index page) implies authorization for the file download. Route obfuscation (like `HashService`) is not a replacement for proper access control.
**Prevention:** Always explicitly verify authorization and ownership on endpoints that return files or direct object references. Specifically, for stateful models like `Payroll`, verify both that `$object->user_id` matches the authenticated user and that `$object->status` indicates the data is finalized (e.g., 'approved_finance', 'paid') before serving the file.
