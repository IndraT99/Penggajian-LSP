## 2024-03-12 - Fix IDOR in PDF Generation
**Vulnerability:** Insecure Direct Object Reference (IDOR) on PDF generation endpoint for employee payslips (`/karyawan/slip-gaji/{payroll}/pdf`). Even though route model binding (`HashIdRoute`) obfuscated the ID, there were no access controls verifying that the currently authenticated employee actually owned the requested payroll, or that it was in a final state (`approved_finance` or `paid`).
**Learning:** Endpoints that generate and return files (like PDFs) are often overlooked when implementing authorization checks, as developers might mistakenly rely on obscured identifiers or focus only on view authorization. Route ID obfuscation alone does not prevent unauthorized access.
**Prevention:** Always implement explicit ownership (`$model->owner_id === $currentUser->id`) and state checks (`in_array($model->status, ['final_state'])`) in controllers before generating or serving sensitive files, regardless of route obfuscation.
