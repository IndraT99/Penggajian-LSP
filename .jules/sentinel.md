## 2024-05-18 - Fix IDOR in PDF Generation Endpoint
**Vulnerability:** The `/karyawan/slip-gaji/{payroll}/pdf` endpoint (in `KaryawanSlipGajiController::generatePDF`) accepted direct object references to the `Payroll` model without validating whether the currently authenticated employee owned that specific payroll record, and also without verifying the state of the payroll record. This allowed any authenticated user to potentially enumerate payroll IDs and download PDF slips belonging to other employees.
**Learning:** Endpoints that generate or return files/documents (like PDFs) are frequently overlooked when implementing authorization checks. Route model binding combined with ID obfuscation (like `HashService`) is not a replacement for explicit access control checks (ownership and state).
**Prevention:** Always explicitly check authorization and ownership against the authenticated user for all endpoints that access direct object references, even if the route uses obfuscated IDs. Verify record state (e.g., `approved_finance` or `paid`) to prevent premature access.
