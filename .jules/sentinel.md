## 2024-05-24 - IDOR in PDF Download (generatePDF)
**Vulnerability:** Insecure Direct Object Reference (IDOR) on PDF generation endpoint `KaryawanSlipGajiController@generatePDF`. The controller accepted a route-injected `Payroll` object but did not check if it belonged to the currently authenticated user before streaming the PDF.
**Learning:** Even if `HashIdRoute` is used, object obfuscation is not authorization. Routes that accept models directly (like via route model binding) MUST verify object ownership against the authenticated user explicitly before performing sensitive actions or returning PII like salary details. Also, we must check object lifecycle status (e.g. `approved_finance` or `paid`) if it represents finalized data.
**Prevention:** Always use a consistent helper method (e.g., `$employee = $this->getAuthenticatedEmployee(); if ($payroll->employee_id !== $employee->id) { abort(403); }`) inside methods that return or manipulate user-specific data passed via route parameters.
