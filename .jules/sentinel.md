## 2024-06-25 - IDOR in PDF Generation
**Vulnerability:** The `generatePDF` method in `KaryawanSlipGajiController` returned a PDF stream based on Route Model Binding (`Payroll $payroll`) without any authorization checks to ensure the currently authenticated user was the owner of the `Payroll` record, or that the `Payroll` was finalized. This allowed any authenticated user to download any other user's salary slip by iterating through valid `Payroll` IDs. Route obfuscation using `HashService` or `HashIdRoute` is not sufficient to prevent this.
**Learning:** Endpoints that generate or return files (like PDFs) are frequently overlooked during access control implementation, as developers often assume the route is obscure or simply forget the authorization layer in utility endpoints.
**Prevention:** Always implement explicit ownership checks (e.g., matching the resource owner ID with the authenticated user ID) and state checks (e.g., verifying `status` is `approved` or `paid`) for every controller method that returns sensitive information or files, even if the model binding or route ID is obfuscated.
