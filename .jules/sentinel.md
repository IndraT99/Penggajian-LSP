## 2024-06-23 - Prevent IDOR on PDF Endpoints
**Vulnerability:** The `generatePDF` method in `KaryawanSlipGajiController` accepted a `Payroll` model via route model binding but lacked authorization checks to verify if the authenticated employee owned the payroll or if the payroll status was finalized. This allowed any authenticated user to guess payroll IDs and view other employees' slip gaji PDFs.
**Learning:** Endpoints that generate or return files (like PDFs) are often overlooked for authorization checks, as the focus is on the view generation rather than access control. Even with obfuscated IDs (like `HashIdRoute`), direct object references must always be explicitly checked for ownership and state.
**Prevention:** Always implement explicit ownership (`$payroll->employee_id === $employee->id`) and state checks (`in_array($payroll->status, [...])`) on all endpoints returning direct object references, including file downloads and PDF generation, before processing the request.
