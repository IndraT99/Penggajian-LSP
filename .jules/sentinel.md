## 2024-05-18 - Missing Authorization on PDF Download Endpoint
**Vulnerability:** The `/karyawan/slip-gaji/{payroll}/pdf` endpoint (in `KaryawanSlipGajiController::generatePDF`) did not verify if the requested `Payroll` object belonged to the authenticated user's employee ID, nor did it verify the `status` of the payroll record. This allowed any authenticated user to download the payroll slip PDF of any other user by iterating through or guessing the `Payroll` ID (Insecure Direct Object Reference - IDOR).
**Learning:** Endpoints that generate and return files (like PDFs) are often overlooked for authorization checks because developers might assume that routing model binding or a separate index view provides sufficient protection. Direct resource access must always have explicit ownership and state checks.
**Prevention:** Always verify ownership (`$resource->user_id === Auth::id()` or similar) and allowed state (`in_array($resource->status, [...])`) on every endpoint that retrieves or interacts with a direct object reference, especially before performing expensive operations like PDF generation or file streaming.
