## 2024-05-18 - Fix IDOR in PDF generation endpoint
**Vulnerability:** Insecure Direct Object Reference (IDOR) in `KaryawanSlipGajiController@generatePDF`. The endpoint accepted a `Payroll` object via route model binding and generated a PDF document, but did not verify whether the payroll belonged to the authenticated user, nor did it verify whether the payroll record had a final status (e.g. `approved_finance` or `paid`).
**Learning:** Endpoints that return files or PDFs rather than standard views are particularly prone to authorization oversights, as developers may focus primarily on the view/PDF generation logic. Route obfuscation techniques are not a substitute for proper authorization checks on endpoints returning direct object references.
**Prevention:** Always implement explicit ownership checks (`$model->owner_id === $currentUser->id`) and state checks (`$model->status === 'final_status'`) on all endpoints that accept direct object references, regardless of whether they return a view, a file, or a PDF.
