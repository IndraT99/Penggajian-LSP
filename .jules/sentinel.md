## 2023-09-23 - Insecure Direct Object Reference (IDOR) in PDF Generation
**Vulnerability:** The `generatePDF` method in `KaryawanSlipGajiController` allowed any authenticated user to download the payroll PDF of any other user simply by providing a valid payroll ID, bypassing authorization checks that were only present in the `show` method. It also allowed downloading PDFs for payrolls that were not yet approved or paid.
**Learning:** Endpoints that generate files or documents (like PDFs) are frequently overlooked for authorization checks, as developers might incorrectly assume route model obfuscation (if present) or the fact that they are "just downloading a file" provides sufficient security. They need the same robust authorization and state checks as standard viewing endpoints.
**Prevention:** Always implement explicit ownership checks (`$model->owner_id === $user->id`) and state checks (`in_array($model->status, ['approved', 'final'])`) on all endpoints returning direct object references or sensitive file downloads, especially when relying on model binding. Never rely on obfuscation or obscurity as a substitute for authorization.
