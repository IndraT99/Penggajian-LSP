## 2024-03-24 - Missing Access Control on PDF Generation Endpoint
**Vulnerability:** Insecure Direct Object Reference (IDOR) on an endpoint generating PDF documents (`/karyawan/slip-gaji/{payroll}/pdf`). Any authenticated user could generate and view other users' payroll PDFs if they knew or guessed the `payroll` ID (even if route obfuscation was in place, as obfuscation is not authorization). The endpoint also lacked state checks, potentially allowing generation of draft/unapproved payrolls.
**Learning:** Developers often focus on the view generation logic for file downloads/PDF exports and may forget to include the standard authorization and ownership checks that exist on normal `show` methods. Route obfuscation (`HashIdRoute`) can give a false sense of security and must not replace explicit access controls.
**Prevention:** Always implement explicit ownership checks (e.g., `if ($payroll->employee_id !== $employee->id)`) and state checks (e.g., `$payroll->status === 'paid'`) on endpoints returning direct object references or files, mirroring the checks on the corresponding `show` endpoint.
