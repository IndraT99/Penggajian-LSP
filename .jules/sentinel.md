## 2024-03-24 - Fix IDOR in Payroll PDF Generation
**Vulnerability:** Insecure Direct Object Reference (IDOR) on the `generatePDF` endpoint in `KaryawanSlipGajiController`. Any authenticated user could guess another employee's hashed route key and download their salary slip PDF, exposing PII and salary information.
**Learning:** Endpoints that generate files or views (like PDFs) are frequently overlooked when applying access control checks, especially when route model binding obscures the ID. Developers often focus solely on the view generation logic rather than authorization. Route obfuscation (`HashIdRoute`) is not a substitute for proper authorization.
**Prevention:** Always implement explicit ownership (`$payroll->employee_id === $employee->id`) and state checks (`in_array($payroll->status, ['approved_finance', 'paid'])`) on all endpoints returning direct object references or generated files. Ensure authorization checks are applied consistently across all related actions (e.g., both `show` and `generatePDF`).
