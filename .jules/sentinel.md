## 2024-03-23 - Insecure Direct Object Reference (IDOR) in PDF Download
**Vulnerability:** The `generatePDF` method in `KaryawanSlipGajiController` allowed any authenticated user to download any other user's salary slip by simply guessing or providing a different `Payroll` ID.
**Learning:** This occurred because the controller method relied solely on Laravel's implicit route model binding to fetch the `Payroll` object without explicitly verifying that the `Payroll` record belonged to the currently authenticated employee. The `show` method had proper authorization checks, but the `generatePDF` endpoint, which returned a direct object reference (the PDF stream), was missing them.
**Prevention:** Always implement explicit authorization checks in controller methods, especially for actions that download or return sensitive resources, even if route model binding is used. Verify that the requested resource belongs to the currently authenticated user (`$model->user_id === auth()->id()`) before processing the request.
