## 2024-05-24 - Missing Authorization Check on PDF Generation (IDOR)
**Vulnerability:** The `generatePDF` method in `KaryawanSlipGajiController` returned a PDF file given a specific `Payroll` object (injected via Route Model Binding), but failed to verify whether the authenticated user owned that payroll or whether the payroll was in a finalized state.
**Learning:** Endpoints that return files (like PDFs or exports) are just as susceptible to IDOR as data-returning endpoints, because developers sometimes focus primarily on the view generation library (`Pdf::loadView`) and overlook authorization. Obfuscation of route keys (via `HashIdRoute` or `HashService`) is not a substitute for proper authorization.
**Prevention:** Always implement explicit ownership checks (e.g. `$payroll->employee_id !== $employee->id`) and state checks (e.g. `!in_array($payroll->status, ['approved_finance', 'paid'])`) on all endpoints that return direct object references, even when using route obfuscation.
