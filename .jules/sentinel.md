## 2025-06-05 - IDOR in PDF Generation Endpoint
**Vulnerability:** Insecure Direct Object Reference (IDOR) on the `KaryawanSlipGajiController::generatePDF` endpoint allowed users to download PDF slips of other employees. The method relied solely on Route Model Binding without explicitly checking the authenticated user's authorization or the status of the payroll record.
**Learning:** Endpoints that generate and return files (like PDFs) are prone to missing authorization checks in this codebase. Developers might focus heavily on the view generation logic and overlook explicitly applying access controls present in other routes like `show`. Route model binding alone is not a sufficient defense against IDOR.
**Prevention:** Always mirror the authorization and status checks from the standard `show` method when implementing corresponding file export or generation endpoints. Consider abstracting these checks into Form Requests or dedicated Authorization Policies instead of placing them inline in the controller methods.
