## 2024-05-24 - Missing Authorization on PDF Generation Endpoint
**Vulnerability:** IDOR (Insecure Direct Object Reference) on the `generatePDF` method in `KaryawanSlipGajiController`. Any authenticated user could potentially guess a payroll ID and generate/download another user's salary slip.
**Learning:** Endpoints that generate or return files (like PDFs) using route model binding must still explicitly check for authorization and ownership. Developers often overlook this because the view generation itself might seem like the primary action, forgetting that the generated file contains sensitive data belonging to a specific user. Route obfuscation (like `HashService`) is not a replacement for these checks.
**Prevention:** Always implement explicit ownership checks (`$model->user_id === $authenticatedUser->id`) and state checks (e.g., ensuring a document is in a finalized state) on endpoints returning direct object references or files, even when route IDs are obfuscated.
