## 2024-05-31 - IDOR Vulnerability in PDF Generation Endpoint
**Vulnerability:** Insecure Direct Object Reference (IDOR) on the PDF generation endpoint `generatePDF(Payroll $payroll)` where authorization checks and status checks were missing, allowing users to generate PDFs for other users' payrolls or draft payrolls by guessing obfuscated route keys.
**Learning:** Endpoints that generate or return files (e.g. PDFs) based on route model binding are frequently overlooked for authorization, even if the `show` method has the correct checks. Developers tend to focus on the file generation logic instead of re-verifying access control. Route ID obfuscation (`HashService`) is not a replacement for proper ownership checks.
**Prevention:** Always replicate ownership (`$payroll->employee_id !== $employee->id`) and state (`status` check) validation in any endpoint that accesses a protected resource, including export, download, or PDF generation endpoints, regardless of route key obfuscation.
