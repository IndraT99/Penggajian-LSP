## 2025-02-18 - Missing Authorization Check on PDF Generation endpoint\n**Vulnerability:** Found an IDOR vulnerability in the `KaryawanSlipGajiController::generatePDF` endpoint, where any authenticated user could download any payroll slip without ownership or status verification.\n**Learning:** The previous implementation only relied on route model binding to inject the `Payroll` object, completely skipping ownership/status checks before rendering the view as a PDF file, assuming obscured IDs were enough.\n**Prevention:** Endpoints generating reports/PDFs or dealing with direct object references must explicitly perform authorization checks, just like view endpoints, independent of route obfuscation mechanisms.
